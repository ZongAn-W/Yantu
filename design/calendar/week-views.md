# 只读日历周视图（上下镜像 / 学习山脉）

> 本文件描述日/周合并前的周视图细节；现在周视图属于合并后的「日历」栏目（日/周/月），周图下方「本周课程执行」汇总已移除，见 [merged-views.md](merged-views.md)。

日历在原有日视图之外新增两个整周图。两种周图共用同一份只读周数据与同一面板结构，切换只改变主图形，不改变日期、学习数据或明细排序。

## 页面与切换

- 顶部只保留紧凑区域：日期导航、`日/周` 切换，周模式提供图形选择；日模式按生长轨道、学习日轮、双河道顺序同时展示三张卡片。不新增页内大标题、副标题或功能介绍。
- 选中日期由日视图与周视图共享：日视图显示该日；周视图显示包含该日的周一至周日（Asia/Shanghai 日期边界）。任意切换都保留所选日期，周范围由该日期确定。
- 日视图导航：前一天 / 后一天 / 今天 / 日期选择；周视图导航：前一周 / 后一周 / 本周 / 日期选择。周模式一次只显示一张主图，不把七天拆成七张图或七张卡片。
- 本机周图形偏好保存在现有 Sembast `calendar-preferences` store 的 `week-view` 记录。刷新后默认入口是三图纵向排列的日视图；旧 `day-view` 记录保留兼容，页面不再读取它。
- 日历完全只读：没有计时、编辑、拖动、删除、标记完成、完成勾选或固定事件入口。

## 共享周数据模型

`CalendarWeekData`（`lib/features/calendar/domain/calendar_week_data.dart`）在展示组件之外由 `buildCalendarWeekData(data, anchorDate)` 构建：

- 七天由 `buildCalendarDayData` 复用现有日模型与 `dayExecutionSummary` 领域统计，每天对象是「当天有排程的事项」与「当天有学习记录的对象」的并集。
- 同一事项当天多条排程合并求和；每条学习记录只归属一次；临时学习转换后同时保留两种引用时只累计一次；同一会话按合法关系/上海日期拆出的多条记录不按 session 合并。
- 分类只来自已有领域事实（`scheduled` / `extra` / `adHoc` / `legacyUnknown` 及当天是否有排程），不用「实际减计划」反推加学；原定未学满时的加学仍表达为加学，其他对象的投入不抵消某事项未执行的计划。
- 已完成或归档状态不补出实际时长；展示的是学习时长，不是内容完成度。
- 周计划 = 七天日统计计划之和；周实学 = 七天日统计实学之和。
- `scaleMinutes` 取整周单日 `max(计划, 实学)` 的最大值（至少 1）。两种周图的计划与实学共用该比例，上下/面积不会分别归一化，超计划投入完整显示。
- `courses` 按周内首次出现的规范事项顺序固定，颜色复用现有课程配色；未知课程使用与日视图相同的稳定散列调色板。
- `layers` 是 `课程 × 投入分类` 的固定顺序层（课程顺序 + 分类枚举顺序），每天记录七个数；某天没有该类投入记 0，不重排、不丢层。
- 明细的对象顺序、名称、课程、计划、实学与分类在两种周图中完全一致，因为面板明细直接读取同一 `CalendarWeekDay.day.items`。

## 上下镜像

- 横轴周一至周日，纵轴学习分钟；共用一条零基线，计划向上、实学向下，两个方向使用同一分钟到像素比例。
- 每天计划按事项分段、浅色填充并描边，只作计划参照；实际学习按课程颜色、事项与分类分段，原定实学为实色，加学/未排程/临时学习/历史记录叠加可区分纹理。
- 下方是正的实际学习时长，不是负数或欠账：图内轴标签与图例写明「实学（分钟，向下；向下代表实际学习时长，不是负数）」。
- 计划外对象只出现在实学一侧，不伪造计划；仅计划、仅实际、空白日都保留七天位置；超计划超出部分不截断。
- 日轴由主图正下方的七个并列日期按钮承担（宽 320px 时仍同时可见），既是触摸/点击入口，也是键盘焦点入口；点击或悬停主图任意一天列会更新同面板内的当天明细。

## 学习山脉

- 横轴仍为周一至周日，纵轴仍为学习分钟；实学按 `课程 × 投入分类` 固定顺序堆叠面积，山形总高度等于当天实学总量。
- 计划总时长用一条清晰虚线轮廓表达，与山形共用同一纵轴比例；虚线不填充，不与实学交叠出「达成面积」，原定执行仍按事项统计。
- 七天的真实采样点是直线连接的多边形顶点，采样日之间没有平滑曲线，不制造未记录的峰谷，也不把跨天连接解释为持续学习或开始时间。每个采样点有实心圆点；空白日显示零位空心点。
- 仅计划的日子仍有计划虚线；仅实际的日子仍显示完整山形；计划外事项同样贡献到真实山形。
- 明细与镜像图完全相同：同一份周数据、同一对象顺序、同一计划/实学/分类数值。

## 信息与无障碍

- 七天始终同时存在于主图；主图绘制日期轴列与分钟刻度，日轴按钮显示周一至周日与日期数字。
- 课程颜色图例（含各课程周计划/周实学语义标签）与分类纹理图例均为文字+纹理/颜色双重表达，不依赖颜色或悬停单独传递信息。
- 周计划、周实学是主图面板顶部的紧凑数值；课程图例只保留课程名称，投入图例压缩为计划、实学和计划外。主图下不常驻事项列表；点击或键盘激活日期后，在按需弹层中查看完整事项名称、课程、计划、实学与各分类时长，悬停只显示紧凑摘要。
- 主图画布不注册无名点击语义；读屏通过七个具名日期按钮获取完整当天事实（计划、实学、各分类）并可激活；主图本身带有整周摘要语义。画布置于图表自身区域内，未用透明控件覆盖主图或选择器。
- 图表无动画过渡；日期按钮在系统减少动画时禁用溅射动画。
- 320px 宽度下主图、图例与明细均为自适应换行/收缩，无横向溢出；短图段不强行加宽，精确值从日期按钮与明细获取。

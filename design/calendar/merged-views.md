# 日历栏目（日 / 周 / 月）

原来的「日历」与「进度」两个导航栏目合并为一个只读「日历」栏目。两个功能共用一条时间轴：

1. 查看规划的计划：按日 / 周 / 月浏览每日安排，以及每天的容量与学习热度；
2. 可视化学习情况：计划与实学对比、课程分布与月度中断。

`/progress` 重定向到 `/calendar`，导航从「今日、日历、进度、调整、设置」变为「今日、日历、调整、设置」。执行仍在今日页，改计划仍在调整页；日历不提供计时、编辑、拖动、删除、标记完成或固定事件入口。

## 页面结构

顶部只有紧凑控件：日期导航（前一天/后一天/今天、前一周/后一周/本周、上个月/下个月/本月，随范围变化）、`日/周/月` 范围切换；周范围保留「上下镜像 / 学习山脉」图形选择并独立记忆本机偏好。范围切换、图形切换与日期选择共享同一个选中日期，不重置它。

日期导航下方是常驻的「累计实际学习 / 本期剩余 / 课程内容完成」概览条。它统计截至今天的事实，不随所选日期变化。

各范围内容：

- **日**：当天总量（计划 / 实学 / 容量）+ 两张日图（生长轨道、计划与实际双河道）。原「当天安排」明细已移除。
- **周**：整周图（上下镜像或学习山脉，含七天日期轴与选中日明细）。原「本周课程执行」汇总已移除；周口径统一为选中日期所在自然周（周一至周日），不再是滚动 7 天。
- **月**：月历网格。每格显示计划 / 每日容量、实学热度（0–4 级）与执行状态；未来日期只显示计划与容量，用来提前查看整段安排。月汇总显示本月计划、实学与中断天数；原「当天安排」展开区域已移除。原来的月度热力图由它承接。
- 页面底部的「学习总览」（课程进度、总体燃尽 / 预计完成）面板已移除；顶部保留紧凑的「累计实际学习 / 本期剩余 / 课程内容完成」概览条。

## 数据与口径

- 日 / 周快照继续使用 `buildCalendarDayData` / `buildCalendarWeekData`；新增 `buildCalendarMonthData` 逐日复用同一日快照，并解析 `resolveDayCapacity` 得到每日容量。
- 月历状态由已封顶的原定达成量决定，不用「实际 − 计划」反推：
  - 完成原定：原定达成 ≥ 当日计划；
  - 部分执行：0 < 原定达成 < 计划；
  - 中断：过去（含今天）有计划但原定达成为 0；
  - 计划外学习：无计划但有真实记录；休息日：容量 0 且无计划无记录；未来有计划：未到。
- 实学热度按当天实学分钟分 0–4 级（每 120 分钟一级），只统计已经发生的日期。
- 临时学习已从客户端下线：历史记录仍保留在存储与同步文档中，但日历与月历统一忽略带 `relation=ad_hoc` 或 `ad_hoc_id` 的历史行，避免同一份数据出现两套累计口径。
- 概览条中的预计完成日期只使用正式事项的实际用时；历史临时学习不计入统计与速度估算。内容是否学完仍以内容反馈确认，不由计时自动完成。

## 只读与无障碍

- 所有图形与状态只读；月历格是具名按钮（含日期、计划、容量、实学与状态），支持键盘与读屏；选中日期用蓝色边框标识，今天用圆环标识。
- 手机 320px 无横向溢出；月历格在窄屏收起文字，仅保留日期、状态与计划/容量细条，完整数值通过语义获取。

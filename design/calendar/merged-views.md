# 日历栏目（日 / 周 / 月）

原来的「日历」与「进度」两个导航栏目合并为一个只读「日历」栏目。两个功能共用一条时间轴：

1. 查看规划的计划：按日 / 周 / 月浏览每日安排，以及每天的容量与学习热度；
2. 可视化学习情况：计划与实学对比、课程分布与月度中断。

`/progress` 重定向到 `/calendar`，导航从「今日、日历、进度、调整、设置」变为「今日、日历、调整、设置」。执行仍在今日页，改计划仍在调整页；日历不提供计时、编辑、拖动、删除、标记完成或固定事件入口。

## 页面结构

顶部只有紧凑控件：日期导航（前一天/后一天/今天、前一周/后一周/本周、上个月/下个月/本月，随范围变化）、`日/周/月` 范围切换；周范围保留「上下镜像 / 学习山脉」图形选择并独立记忆本机偏好。范围切换、图形切换与日期选择共享同一个选中日期，不重置它。

日期导航下方是常驻的「累计实际学习 / 本期剩余 / 课程内容完成」概览条。它统计截至今天的事实，不随所选日期变化。

日 / 周 / 月三个范围的内容最上方都有一张「本期完成事项」时间饼图（环形图）：分片为当前选中日 / 自然周（周一至周日）/ 自然月内**有实际学习记录**的事项，面积对应该事项本期的实际用时；中心显示本期总实学时长与事项数，图例列出事项名、时长与百分比。饼图随选中日期和范围切换同步变化，只读、无计时或完成入口。

各范围内容：

- **日**：本期完成事项饼图 + 当天总量（计划 / 实学 / 容量）+ 两张日图（生长轨道、计划与实际双河道）。原「当天安排」明细已移除。
- **周**：本期完成事项饼图 + 整周图（上下镜像或学习山脉，含七天日期轴与选中日明细）。原「本周课程执行」汇总已移除；周口径统一为选中日期所在自然周（周一至周日），不再是滚动 7 天。
- **月**：本期完成事项饼图 + 学习马赛克月历。每格只有日期与课程色块：方块 = 当日容量，色块面积 = 各课程计划分钟，填充高度 = 计划 / 容量，浅色 = 未排满容量；今天实心蓝圆、选中 2px 描边、超容量琥珀圆点。宽屏（内容 ≥940）网格右侧为选中日计划栏，窄屏堆到网格下方并带「在日视图中查看」入口；<620 用缩小的马赛克方块。月汇总只含计划口径（本月计划 / 学习日 / 超容量天数），不再展示实学、状态或热度；原「当天安排」展开区域已移除。
- 页面底部的「学习总览」（课程进度、总体燃尽 / 预计完成）面板已移除；顶部保留紧凑的「累计实际学习 / 本期剩余 / 课程内容完成」概览条。

## 数据与口径

- 日 / 周快照继续使用 `buildCalendarDayData` / `buildCalendarWeekData`；新增 `buildCalendarMonthData` 逐日复用同一日快照，并解析 `resolveDayCapacity` 得到每日容量。
- 月历状态由已封顶的原定达成量决定，不用「实际 − 计划」反推：
  - 完成原定：原定达成 ≥ 当日计划；
  - 部分执行：0 < 原定达成 < 计划；
  - 中断：过去（含今天）有计划但原定达成为 0；
  - 计划外学习：无计划但有真实记录；休息日：容量 0 且无计划无记录；未来有计划：未到。
- 实学热度按当天实学分钟分 0–4 级（每 120 分钟一级），只统计已经发生的日期。
- 本期完成事项饼图复用同一批日快照：`buildCalendarCompletionData` 按 owner 汇总实学分钟，只保留实学 > 0 的事项；日 / 周 / 月的分母分别是 1 天、7 天、整月快照之和。无任务引用的历史日志合并为「历史学习记录」，任务已删除的记录合并为「已删除事项」，两者都不再带标签色。
- 分片颜色优先取事项第一个有颜色的标签（`#rrggbb`，暗色经 `dataTone` 提亮），没有标签色时按 owner id 稳定散列取 `tagFallbackColors`，因此同一事项在不同日期/范围保持同一颜色。同一标签的多个事项保留同一色相：重复颜色按分片出现顺序向纸质底色/墨色微提亮（18%/36%/54%），既保持「同课程同色系」又能在环上区分；只有色相族用尽时才回退散列色。超过 8 个事项时前 7 个 + 「其他 N 个事项」，中心事项数仍是真实值；百分比用最大余数法取整且合计恰为 100%，非零事项至少显示 1%。
- 临时学习已从客户端下线：历史记录仍保留在存储与同步文档中，但日历与月历统一忽略带 `relation=ad_hoc` 或 `ad_hoc_id` 的历史行，避免同一份数据出现两套累计口径。
- 概览条中的预计完成日期只使用正式事项的实际用时；历史临时学习不计入统计与速度估算。内容是否学完仍以内容反馈确认，不由计时自动完成。

## 只读与无障碍

- 所有图形与状态只读；月历格是具名按钮（日期、计划、容量、各事项计划时长，支持键盘与读屏）；选中日期用 2px 墨蓝描边，今天用实心蓝圆；超容量显示琥珀圆点。
- 手机 320px 无横向溢出；月历格在窄屏用缩小的课程色块，完整数值通过语义获取；选中日计划在网格下方。

## 2. 设计目标

把“事项管理”从**字段密集的表格**改成**课程优先的图形化目录**：

- 先看课程，再看事项；课程是视觉主角，事项是课程里的条目。
- 每个课程像一个文件夹：头部是标签（图标 + 名称 + 数量 + 添加），展开内容直接铺开，**不再套一层事项卡片**。
- 列表只展示**事项名称**；说明仍保留在编辑弹窗的数据里，但不在列表中渲染。管理动作收进 `⋯`，页面安静、可扫读。
- 保留现有蓝灰色调与既有组件语言（白面板、1px 边线、8–12px 圆角、无渐变、无大面积装饰）。

## 3. 信息架构与布局

### 桌面端（≥ 1080px，双列）

```
┌ 侧边栏 240 ┐┌────────────────────────────── 主区 ─────────────────────────────┐
│ 品牌 / 导航 ││ 事项管理 [示例数据]              [搜索] [课程筛选] [+ 新建课程]   │
│ …          ││ 按课程分组查看和管理学习事项                                     │
│ 事项（选中）││ ┌─ 课程文件夹 ─────────┐  ┌─ 课程文件夹 ─────────┐              │
│ …          ││ │ 图标 课程名 5 个事项 +添加│  │ …                    │              │
│            ││ │ 事项标题              ⋯ │  │                      │              │
│ 学习目标    ││ │ …（细分隔线）           │  │                      │              │
└────────────┘│ └──────────────────────┘  └──────────────────────┘              │
              │ 左右两列各自独立向下堆叠，互不牵制课程高度                        │
```

- 主区最大宽度 1200px（含 32px 内边距），1440px 下内容区 1136px，两列各约 559px。
- 桌面双列是**两条独立列流**：左列课程 1/3/5，右列课程 2/4/6；每列只对自身高度负责，课程高度不等时不会在另一列留下行间空洞。
- 列内课程间距固定 18px；两列共享顶部起点，底部自然错落。
- 搜索或筛选只剩一门课程时，自动回到完整单列（1136px），不再占半列。
- 桌面上事项文本与课程名对齐（缩进 65px），从属关系直接可见。
- 空课程仍占位，用居中的空状态 + 头部唯一添加入口，不重复给按钮。

### 平板端（900–1079px，单列）

- 保留左侧栏，但主区改为单列，避免 900px 时课程名被压成“高等…”这种 2–3 个字。
- 1024px 下内容宽约 720px，课程名、事项名称均完整。

### 移动端（< 900px，单列）

```
┌ 不白学        ● 云端已同步  (头像) ┐
│ 事项管理 [示例数据]      [+ 新建课程] │
│ 按课程分组查看和管理学习事项          │
│ [🔍 搜索事项]        [全部课程 ▾]    │
│ ┌ 课程文件夹 ──────────────────────┐ │
│ │ 图标 课程名 5 个事项     + 添加事项 │ │
│ │ 事项标题                        ⋯ │ │
│ └─────────────────────────────────┘ │
│ …（单列，课程间距 12px）              │
│ 示例数据说明                         │
├ 今日 日历 事项 进度 调整 访谈 设置 ┤
└─────────────────────────────────┘
```

- 390px 与 320px 下均实测 `scrollWidth = innerWidth`，无横向溢出。
- 移动端不强制 65px 缩进，优先保证 250px 以上的正文宽度；层级靠课程头、书脊和分组延续。
- 底部导航沿用现有 App 的 7 个入口；手机端顶部用品牌栏（避免与页面标题重复）。

## 4. 视觉规范（沿用项目现有 token）

| Token | 值 | 用途 |
| --- | --- | --- |
| 背景 | `#f5f7fa` | 工作区底色 |
| 面板 | `#ffffff` | 课程文件夹、控件、弹窗 |
| 主文字 | `#20334a` | 标题、事项名称 |
| 次级文字 | `#5b6b7d` | 计数、辅助信息 |
| 主蓝 | `#275e91` | 主按钮、选中态、链接型入口 |
| 绿 / 橙 / 危险 | `#237354` / `#a85c14` / `#b3261e` | 同步状态 / 课程色 / 删除 |
| 边线 | `#dce3eb` | 面板外框 |
| 细分隔线 | `#e9eef4` | 事项行之间 |
| 课程头部 | `#f8fafc` | 中性蓝灰标签底，不再叠课程色 |
| 字体 | `Noto Sans SC` → `Microsoft YaHei UI` 系统回退 | 中文界面 |
| 圆角 | 面板 12px、控件 8px、图标瓦片 10px | 保持一致 |
| 阴影 | 仅浮层/弹窗使用 | 面板不用重阴影 |

课程强调色不是新造色板，直接取现有 `apps/flutter_client/lib/core/theme.dart` 的 `subjectColors`：
`#4565c7 / #1f7a5a / #c2761f / #5b7fd4 / #2b7f9e / #8a5a2b`，按课程固定。
为控制“少量颜色”，**头部底色改为中性蓝灰**，课程色只出现在 3px 书脊与 38px 图标瓦片上。
若产品希望进一步收敛，可只保留蓝/绿/橙三色，图标仍然能区分课程。

### “文件夹感”是怎么做出来的

1. **课程 = 文件夹，事项 = 夹内条目**：课程头是标签区（中性底 + 图标 + 名称 + 数量 + 添加入口），下面直接是事项行，没有内层卡片。
2. **左侧 3px 课程色书脊**：每条课程面板左缘一条 48% 明度的课程色线，面积小但能快速区分课程。
3. **38px 实色课程图标瓦片**：不同课程用不同线性图标（函数曲线 / A / 二叉树 / 矩阵 / 网络 / 芯片），白描边、课程色底。
4. **桌面缩进对齐**：事项文本与课程名同列（65px），像文件夹标签下的内容；手机端优先保证阅读宽度。
5. **双列独立堆叠 + 细线分隔**：左右列各自负责自身高度，避免另一列的高课程把本列课程往下顶；事项之间只用 12px 上下留白 + 1px 分隔线，不制造卡片噪音。

## 5. 组件规则

### 课程头部
- 高度约 64px；图标 38px；课程名 15.5px / 600；数量 11.5px / 次级色；添加入口右对齐（`+ 添加事项`，12.5px 蓝色文字按钮）。
- 课程数为 `0 个事项` 时仍完整显示头部与添加入口。
- 搜索时数量显示为“匹配 / 总数”（如 `1 / 5 个事项`），不再与可见条目数矛盾。

### 事项行
- 只展示**名称**（14.5px / 600 / `#20334a`；长标题允许自然换行，示例标题 37 字在桌面占 2 行，名称不截断）。**说明不在列表中渲染**，只在编辑弹窗中维护。
- 右侧**只有**一个 `⋯` 按钮（桌面 30px；手机 38px 视觉，命中区扩到 44px），没有编辑/删除/计时/排程等并列图标；按钮与标题第一行顶部对齐。
- 行内边距 12px / 18px；桌面上为 65px，与课程名对齐。行与行 1px `#e9eef4` 分隔线；hover 只做 `#f8fafc` 背景。

### 空课程
- 头部保留；内容区居中显示“这门课程还没有事项 + 可使用上方「添加事项」创建第一个事项”。
- 只有头部一个添加入口，不再出现第二个重复按钮。

### 顶部工具
- 左：`事项管理` + `示例数据` 胶囊 + 一行说明。
- 右：紧凑搜索框（224px 桌面 / 弹性手机宽）、课程筛选（含当前课程色点与数量）、主按钮 `+ 新建课程`。
- 不出现状态、优先级、日期等任何额外筛选。

### 新建课程
- 顶部主按钮 `+ 新建课程` 打开弹窗，字段只有：课程名称（必填）、课程颜色（6 个现有色板单选）。
- 新课程使用通用书本图标，所选颜色用于图标瓦片与左侧书脊；创建后得到空课程文件夹，可直接用课程头「添加事项」继续。
- 侧栏「课程 / 事项」统计随创建、编辑、删除实时更新。
- 如果创建时处于搜索或课程筛选状态，创建成功后自动重置为全部课程，确保新课程可见；随后滚动到新课程并把焦点交给它的添加入口。
- 事项的新建入口保留在每门课程头部（`+ 添加事项`），仍自动带入所属课程。

### 搜索与筛选
- 搜索只匹配事项名称与课程名（不匹配未展示的说明）；结果按课程分组保留，课程头显示匹配数 / 总数。
- 无结果时整块空状态：“没有找到与「关键词」匹配的事项” + `清除搜索`；若同时有课程筛选，额外提供 `切换全部课程`，文案会说明当前筛选范围。
- 课程筛选菜单含“全部课程 + 6 门课程（带课程色点与事项数）”；选中行有浅蓝底与加粗标签；菜单最大高度 420px，可在内部滚动。
- 结果变化通过 `aria-live` 区域播报（“找到 N 个事项” / “没有匹配事项”）。

### 事项菜单 / 编辑 / 删除 / 新建
- `⋯` 菜单只有两项：`编辑事项`、`删除事项`（危险色）；焦点有清晰蓝框，Tab 离开即关闭浮层。
- 编辑弹窗：名称（必填）、说明（选填，**仅在编辑弹窗中维护，不进入列表展示**）、所属课程（必填，带课程色点），可跨课程移动；保存后滚动到目标行、短暂高亮，并把焦点交给该行 `⋯`。
- 删除弹窗：展示事项名称，说明“删除后无法恢复，请谨慎操作”，初始焦点在 `取消`，警告通过 `aria-describedby` 关联；删除后焦点移到相邻事项。
- 新建事项弹窗：仅从每门课程头部的 `+ 添加事项` 进入，自动选中该课程并显示“已自动带入所属课程”。名称或课程为空时保存按钮禁用。保存后同样滚动 + 高亮 + 聚焦新行。
- 以上弹窗均支持 Esc 关闭、Tab 焦点循环、关闭后焦点回到触发按钮；移动端使用 `100dvh` 高度约束与 44px 按钮，并保持底部操作区可见。

## 8. 响应式与无障碍

- 断点：<900px 手机壳（品牌栏 + 单列 + 底部导航）；900–1079px 平板（侧栏 + 单列）；≥1080px 桌面（侧栏 + 双列）。
- 已实测：1440 双列、1024/900 单列且课程名不截断、390/320 无横向溢出；320px 下工具栏自动换行。
- 触控目标：手机端 `⋯` 38px 视觉 + 伪元素扩到 44px 命中区；新建/课程添加/筛选/清除按钮均通过伪元素扩展到约 44px；菜单行与弹窗按钮 ≥44px；清除按钮 ≥24px。
- 键盘：菜单 roving focus（↑/↓）、Esc 关闭、Tab 离开即收起；弹窗 Tab 循环与 Esc 关闭；操作后焦点回到新行 `⋯` / 相邻行。
- 语义：`role="menu"` / `menuitem` / `menuitemradio`、`aria-expanded`、`aria-checked`、`aria-describedby`、`aria-live` 结果播报、`role="status"` toast。
- 对比度：占位符/弱文本提高到 `#68788a`；焦点环改为实色 `#275e91`。
- 支持 `prefers-reduced-motion`。
- 说明：`09-mobile-overview.png` 为整页截图，底栏通过 capture 模式回到文档流末端；运行时底栏为 `position:fixed`，以 `12-mobile-first-screen.png` 为准。

## 9. 明确不做（与需求一致）

- 不显示时间投入、预计时长、进度条、圆环、起止日期、截止日期、优先级、状态。
- 不设“当前 / 后续 / 已完成”页签，也不按状态分组。
- 不提供计时、排程、标记完成、加学等执行动作。
- 不在课程卡片内部再包事项卡片；课程内只有列表行。
- 不新增品牌色、渐变、插画或大面积装饰；课程色复用现有 `subjectColors`。
